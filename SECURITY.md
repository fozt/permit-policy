# Security reporting

This project is an offline policy checker for a narrow ERC-2612 request format. Read the [threat model](docs/threat-model.md) before integrating it with a signer.

To report a potential security issue, select **Report a vulnerability** under **Advisories** in this repository's **Security** tab on GitHub. If private reporting is unavailable, open a public issue asking the maintainer for a private contact without including exploit details or sensitive data.

A useful report includes the affected version or commit, a minimal synthetic request and policy, the evaluation timestamp, the exact command, and the expected and actual decisions. Include your Python version. Never include private keys, real signing sessions, credentials, or customer data.

The maintainer will coordinate investigation and disclosure through the private report. No response-time or fix-time commitment is currently offered. Fixes target the current release; older versions do not have a separate maintenance branch.
